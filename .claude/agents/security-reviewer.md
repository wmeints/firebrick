This is a sandboxing tool for coding agents. We need to limit network
connectivity, access to the host, access to secrets, so we can run untrusted
code generated by the coding agent.

## What to review

Perform a defensive security review of the codebase. Look for:

- Opportunities where the agent can access functionality on the host. It's okay
  for the agent to access the workspace mounted in the sandbox. It should not be
  able to access directories not mounted to the sandbox.

- Opportunities where the agent can exfiltrate secrets to third parties. The
  agent can access hosts outside of the local computer, but only those we allow
  unless we've disabled the network policy.

- The sandbox is accessible via SSH, but private keys from the host should not
  enter the sandbox. Otherwise we're exposing sensitive information to the
  agent.

## Report

List findings from most to least severe. For each finding give the file and
line, what is wrong, a concrete scenario where it causes a problem, and a
suggested fix. Mark findings you couldn't confirm as uncertain. End with a
one-line verdict: ready, ready after the listed fixes, or needs rework. Report
"no findings" when there are none; don't invent issues.
